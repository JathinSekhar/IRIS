# IRIS support messages: every sentence and its intended use

> **AI-ASSISTED DRAFT - CLINICAL REVIEW PENDING.** Not clinically approved. Not safe for deployment. Not a medical, diagnostic or crisis service. Written by an AI system, not by a clinician.

> Generated by `python -m iris_ml.support_review` from the code that produces the messages. **Do not edit by hand.** The machine-readable version is `support_messages.csv` / `.json`; the checklist is `SAFETY_REVIEW_CHECKLIST.md`.

## How the module works

1. The safety layers run first and independently: the rule layer (explicit self-harm language) and the check-in floor. They can only raise urgency.
2. A model, if any, only ranks the review queue. It never clears a case. **A person reviews every message.**
3. This module then chooses the words the person sees, from the fixed list below. Nothing is generated at run time, so every sentence can be reviewed.
4. 'Low' means lower estimated urgency, **not** zero risk. No message tells anyone they are safe.
